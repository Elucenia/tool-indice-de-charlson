# مؤشر Charlson للأمراض المصاحبة

[الشروط والمصادر والأذونات](https://elucenia.org/ar/tools/indice-de-charlson)

## كيفية الاستخدام

استخدم الأداة في البوابة أو افتح index.html عبر خادم HTTP محلي. اختر اللغة، وأكمل الحقول، ثم أجرِ الحساب.

## المدخلات والوحدات

### العمر

`idade`

- `0` — \< ٥٠
- `1` — ٥٠ إلى ٥٩
- `2` — ٦٠ إلى ٦٩
- `3` — ٧٠ إلى ٧٩
- `4` — ≥ ٨٠

### احتشاء قلبي سابق

`iam`

### فشل القلب الاحتقاني

`icc`

### مرض الشرايين الطرفية (أو أم دم أبهرية ≥ ٦ cm)

`dap`

### مرض وعائي دماغي (سكتة مع أثر بسيط أو نوبة إقفارية عابرة)

`avc`

### خرف

`demencia`

### مرض رئوي مزمن

`dpoc`

### مرض النسيج الضام (الذئبة أو التهاب العضلات المتعدد أو التهاب المفاصل الروماتويدي أو ألم العضلات الروماتيزمي)

`colageno`

### مرض القرحة الهضمية

`ulcera`

### مرض كبدي

`figado`

- `0` — لا
- `1` — خفيف (التهاب كبد مزمن أو تشمّع دون فرط ضغط بابي)
- `3` — متوسّط أو شديد (تشمّع مع فرط ضغط بابي)

### داء السكري

`dm`

- `0` — لا
- `1` — دون أذيّة عضو مستهدف
- `2` — مع أذيّة عضو مستهدف

### شلل نصفي

`hemiplegia`

### مرض كلوي متوسط أو شديد (كرياتينين \> ٣ mg/dL أو غسيل أو زرع)

`renal`

### ورم صلب

`tumor`

- `0` — لا
- `2` — دون نقائل (آخر ٥ سنوات)
- `6` — نقيلي

### ابيضاض الدم

`leucemia`

### لمفوما

`linfoma`

### الإيدز (وليس مجرد إيجابية HIV)

`aids`

## إصدار الطريقة

CCI/شارلسون 1987؛ تعديل العمر 1994؛ نقاط 50–59/60–69/70–79/≥80؛ تقدير البقاء المحلي

## المعادلة الموثقة

1 نقطة: احتشاء، قصور قلب، مرض شرياني محيطي، مرض وعائي دماغي، خرف، مرض رئوي مزمن، مرض نسيج ضام، قرحة هضمية، مرض كبدي خفيف، سكري بلا أذية عضو هدف. نقطتان (2): شلل نصفي، مرض كلوي متوسط/شديد، سكري مع أذية عضو، ورم صلب، ابيضاض الدم، لمفومة. 3 نقاط: مرض كبدي متوسط/شديد. 6 نقاط: ورم نقائلي، إيدز.

تعديل العمر (شارلسون 1994): 1 نقطة لكل عقد من عمر 50 (50–59=1؛ 60–69=2؛ 70–79=3؛ ≥80=4).

البقاء المقدّر 10 سنوات = 0.983e(0.9 × المؤشر) × 100%.

## الحدود والفئة السكانية

حدّد ما إذا كان المؤشر يتضمن تعديلًا حسب العمر. إنه مقياس إنذاري للأمراض المصاحبة دُرس في أتراب وأطر زمنية محددة، وليس تنبؤًا صالحًا للجميع. تتطلب معادلة البقاء المحلية تحققًا ومعايرة خاصين بها؛ ولا يثبت وجود المرجع الببليوغرافي أداءها الفردي.
